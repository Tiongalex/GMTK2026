# Screenshots Folder

Place your game pictures and screenshots here to have them automatically display in the root [README.md](../README.md):

- `banner.png`: Main cover/banner image (Recommended 1920x1080 or 1280x720)
- `gameplay_candle.png`: Screenshot showing candle exploration
- `gameplay_talisman.png`: Screenshot of the talisman drawing minigame
- `gameplay_ghost.png`: Screenshot of an encounter with the ghost
- `gameplay_door.png`: Screenshot showing the escape door
